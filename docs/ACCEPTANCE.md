# Live workflow check

1. Put the cursor in a blank text document. Start dictation with the existing shortcut. Confirm the floating orb appears immediately and its level changes when you speak and goes quiet when you stop speaking.
2. Stop using the shortcut, release the hold key, or click the orb. Confirm the preview shows the transcript and remains open for review.
3. Press Enter. Confirm exactly one copy appears in the original document and no Return/newline or submit action is sent.
4. Record again, click Copy, and paste manually. Confirm the copied text matches the preview. Press Escape to dismiss.
5. Start and cancel a recording. Confirm the indicator disappears, recording stops, and the original microphone input volume is restored when boosting is enabled.
6. Check History for the new transcript and existing records. Confirm the About section credits the original AudioWhisper project.

If direct paste cannot proceed, the preview must remain available and the transcript must remain copied. The app must not choose an unrelated application. Accessibility permission may need to be enabled for the installed app before direct paste can be exercised.
