# Live workflow check

1. Start dictation with the existing shortcut. Confirm the small listening orb and timer appear at the exact center of the screen containing the pointer, and the level follows your voice.
2. Stop recording. Confirm the same small bar shows transcription progress and disappears when transcription finishes.
3. Press ⌘V in a text document. Confirm the completed transcript appears exactly once. No review panel or Accessibility prompt should appear.
4. Record again and repeat. The new transcript should replace the previous clipboard text.
5. Cancel a recording. Confirm it stops and microphone input volume is restored when boosting is enabled.
6. Check History for new and existing transcripts. About continues to credit the original AudioWhisper project.

The backend currently transcribes after stopping. Partial words are not streamed while recording.
